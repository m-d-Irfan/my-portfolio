# Django backend — pinned dependencies.
#
# Every version is exact. A range means two developers and the production server
# can run different code from the same file, and the difference only surfaces
# under load. Upgrade deliberately: bump one line, run the suite, commit.
#
# Install:  pip install -r requirements.txt
# Audit:    pip-audit          (add to CI; fails on a known CVE)
# Upgrade:  pip list --outdated
