## 🌟 Key Highlights & Features

- **⚡ Cinematic Interactive Showcase**:
  - **3D Coverflow Project Carousel**: Hardware-accelerated 3D project cards with auto-timer, mouse-hover pause, touch swipe gestures, and comprehensive deep-dive detail modals.
  - **Dynamic 3D Dice Roll-Down Designation Rotator**: Smooth cylindrical roll-down title transition cycling through core roles every 2.0 seconds.
  - **Physics-Based Certifications Vertical Carousel**: Direction-aware vertical slide transitions with glowing active indicators and mouse-wheel/swipe controls.
  - **Animated Impact Metrics**: High-precision `requestAnimationFrame` count-up counter (CGPA, Training Hours, Endpoints).
  - **Ultra-Smooth View Transitions Theme Toggle**: Flicker-free circular ripple mask theme switcher between Dark (`night`) and Light (`emerald`) modes.
  - **Back-to-Top Floating Button**: Floating action button with live circular scroll progress tracking and smooth return animation.

- **📄 Dedicated Printable Resume View**:
  - Clean, recruiter-friendly single-page CV layout with instant PDF download and print-ready styles (`@media print`).
  - Hover-only underline links for maximum typographic elegance.

- **🛠️ Zero Framework Overengineering in Demo Sites**:
  - Pure HTML5 semantic architecture + Modular Vanilla CSS token system + Vanilla ES6 Modules for lightning-fast 100/100 Lighthouse performance.

## 🚀 Quick Start & Local Development

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/m-d-Irfan/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
